## Equipment return (`equipment-return`)

`Module: none (manual / logistics)` · `Mode: manual` · `Build tier: 3` · `Lanes: offboard`

Shipping logistics for recovering equipment from a departing remote user (e.g. UOVO).

### Offboard lane
`on-request`. Create a procurement request for shipping materials (return box + label are
POC-preapproved for some clients). Email the shipping label(s) to the separated employee,
CC IT support and the original requestor. Note the total number of boxes on the case.

### Config keys
`preapproved`, `ccItSupport`, `ccRequestor`.

### Functions
None — manual/procurement checklist.

### Depends on
none.

### Variants & gotchas
Pre-approval varies by client; box count recorded on the case; coordinated with the People
team CC list on some clients.

### Manual fallback
Manual by design (procurement + logistics).
