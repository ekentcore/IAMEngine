## Microsoft 365 (`m365`)

`Module: Coretelligent.M365` · `Mode: api` · `Build tier: 1` · `Appears in: ~90%` · `Lanes: both` · STATUS: BUILT (reference module)

User creation, licensing, group membership, alias. Identity origin for `entra`-backbone
clients; a downstream mirror for `google`/`ad` clients (reuses the upstream password).

### Auth
Secret: `m365-admin` (Graph app registration; prefer certificate auth). Scopes:
`User.ReadWrite.All`, `Group.ReadWrite.All`, `Organization.Read.All`.

### Onboard lane
`always`. (1) Ensure user exists (idempotent by UPN) — create with compliant password
(`New-CtgCompliantPassword`) and `requireChangeAtSignIn`; for mirror clients, set the same
username/password as the upstream Google/AD account instead of generating. (2) Assign
licenses by diff (add only missing); procure if unavailable. (3) Add to groups — skip
dynamic groups (verify only). (4) Add alias if requested. Post: licensed, in groups.

### Offboard lane
`always` (the 365-admin teardown; Entra/Exchange handled in their own modules). Block
sign-in, remove from all groups (capture evidence first), back up OneDrive if retention
policy < 1 year to the designated location, remove license — honoring ordering ("do not
remove until after mailbox conversion") and the mailbox size threshold (keep E3 if > 50 GB).

### Config keys
`licenses[]` ({name, skuId}), `procureIfUnavailable`, `procurementChannel`, `groups[]`,
`dynamicGroups[]`, `alias{enabled,address}`, `oneDriveBackup{target,folder,onlyIfRetentionUnderDays}`,
`mailbox{sizeThresholdGB,aboveThreshold}`, `removeLicense{defer,removedBy}`.

### Functions
`Connect-CtgM365`, `New-CtgCompliantPassword`, `Invoke-CtgM365Onboarding` (built);
add `Invoke-CtgM365Offboarding`, `Set-CtgM365MailboxThresholdPolicy`.

### Depends on
`servicenow` (onboard). For mirror clients, depends on `google-workspace`/`active-directory`
(password origin). Offboard: license removal after `exchange`.

### Variants & gotchas
Dynamic groups (verify, don't add); Copilot / Audio Conferencing / E5 Compliance add-ons;
"same creds as GSuite/AD" mirror clients; > 50 GB keep-license rule; "do not remove license
yet" ordering; verify SKU GUIDs against the tenant with `Get-MgSubscribedSku`.

### Manual fallback
None expected (clean API).
